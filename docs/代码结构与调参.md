## 保留范围

- 四个机构：底盘、云台、拨弹、双摩擦轮；拨弹和摩擦轮共用 `module/shoot`。
- 遥控：CRSF/ELRS，接口 UART2 对应 STM32 USART1；遥控解锁、断联处理不变。
- 云台姿态：BMI088、AHRS、IMU 加热与陀螺仪校准。
- 自瞄：`device/ai` / `task/ai` 的 UART 通信、`task/command` 的上位机命令处理，以及 USB 的 V2G/TRAJ 目标接口。
- USB：调参、标定、遥测、故障快照、紧急停止和云台目标输入。
- 基础外设：保留 C 板全部 BSP、CubeMX HAL、FreeRTOS 和 USB Device；不手工裁剪厂商驱动，避免影响 CubeMX 再生成。

## USART6 导航链路

`Task_NavLink` 使用 USART6（115200、8N1，PG14 为 TX、PG9 为 RX），以 DMA 接收导航指令并每 20 ms 回传底盘速度。首次收到有效导航帧后，导航指令优先于 CRSF 底盘指令；指令超过 250 ms 未更新时底盘切换到刹车模式，不自动回退到遥控控制。重新上电且未收到导航帧时，底盘继续使用现有遥控输入。CAN 底盘反馈超时仍会将底盘切到卸力模式。

帧格式为 `AA 55 type sequence length payload crc16`。`type=0x01` 是导航指令，`type=0x02` 是底盘速度遥测；`length=12`，负载依次为小端有符号 `int32` 的 `vx`（mm/s）、`vy`（mm/s）、`wz`（mrad/s）。CRC 使用初值 `0xFFFF`、多项式 `0x1021`，覆盖 `type` 至负载末尾，结果按小端发送。导航链路与保留的 UART AI 驱动共用 USART6；当前启动配置只启用导航链路，不要同时启动 `Task_Ai`。

## 调参只看这里

所有 PID、LADRC、云台前馈的默认值集中在 `User/module/control_params.c`。算法实现不再分散保存这些默认值；`module/config.c` 只负责 Flash 配置读取和保存。

| 对象 | 调参入口 | 实际用途 |
| --- | --- | --- |
| 底盘四轮 | `TUNE_CHASSIS_WHEEL` | 四轮共用的转速 PID |
| 底盘跟随 | `TUNE_CHASSIS_FOLLOW` | 跟随云台的角度 PID |
| 云台 Yaw/Pitch | `gimbal_ladrc_yaw_param` / `gimbal_ladrc_pit_param` | 默认启用的控制器 |
| 云台备用 PID | `TUNE_GIMBAL_*` | Yaw 关闭 LADRC 后使用串级 PID；Pitch 关闭 LADRC 后保持零输出 |
| 摩擦轮 | `TUNE_FRICTION_SPEED` | 双摩擦轮共用的转速 PI；NO_D 模式不使用表内 d 值 |
| 拨弹 | `TUNE_FEEDER_ANGLE` | 拨弹盘角度 PID |
| IMU 加热 | `imu_temp_ctrl_pid_param` | 温度控制，与电机 PID 无关 |
| 云台前馈 | `gimbal_yaw_friction` / `gimbal_pitch_friction` / `gimbal_pitch_gravity` | 摩擦/重力补偿，不能作为 PID 增益调节 |

PID 表的列顺序是 `k, p, i, d, i_limit, out_limit, d_cutoff_freq, range`；实际比例增益是 `k * p`。速度使用电机转子 RPM，角度使用弧度，电机输出为归一化值。

`default` / `infantry` 指向同一套硬件参数。`hero` 仍保留不同的反向、减速比、拨弹齿数及参数，因为现有 Flash 可能选择此车型，不能在清理时擅自改成另一套。共同 PID 定义已合并，只有真实差异保留 `_HERO` 定义。USB 运行时调参仍然有效，重启后重新使用文件中的默认值。

本次没有更改 PID、LADRC、前馈默认增益及限幅。两套机器人参数、两套操作员参数、LADRC/前馈/抖动开关与参数、IMU 温控共 17 组对象的编译后二进制内容均与清理前一致。

## 云台电流保护

Yaw/Pitch 分别按 CAN 反馈电流的绝对值判断：连续超过 **5.0 A** 达 **300 ms** 才触发电流停机；回到 5.0 A 或以下立即清零累计。使能后的启动宽限保留 200 ms。已取消“指令超过 0.6 A、反馈方向或幅值未跟上”的判停条件，因此不再因这种跟踪不匹配锁止。非有限电流反馈仍判异常。

阈值和时间位于 `User/task/ctrl_gimbal.c` 的 `GIMBAL_OVERCURRENT_LIMIT_A` / `GIMBAL_OVERCURRENT_TIME_MS`。诊断变量 `gimbal_actuator_mismatch_count` 及快照/遥测字段沿用旧名称，以兼容现有客户端，其含义改为连续过流计数。

5 A 是软件按当前 CAN 换算得到的反馈阈值，不是指令上限或电机额定值；`CAN_GM6020_MAX_ABS_CUR` 的换算比例仍需实测校准。通信、姿态及输出有效性等其他保护保持原有逻辑。此调整不自动烧录到开发板。

## 装车后的 LADRC 输出预算

Yaw/Pitch 的 `out_limit` 均由 0.30 提高到 **0.60**，位于 `User/module/control_params.c`。这是归一化 CAN 指令的 60%，不是 0.6 A。LADRC 内部和前馈叠加后的最终输出均按该参数限幅；CAN 满量程硬边界仍为 1.0。

按当前代码的指令标度（归一化 1.0 对应 3 A）计算，0.30/0.60 分别对应约 0.9/1.8 A 指令；实际电流需以校准后的反馈和测量为准。此前的 0.6 A 只是启动电流跟踪异常检查的门槛，不是输出上限；5 A 是反馈异常停机阈值，也不是放行 5 A 指令。

装车后转动惯量增大，按相同角加速度运动需要更多力矩，扩大输出预算可以减轻饱和。二阶 LADRC 的 b0 表示输出到角加速度的估计增益，机构惯量增大通常使其幅值下降；原实验台的 Yaw=500/Pitch=550 及带宽暂时保留，需根据装车后的响应重新辨识，不能仅靠提高限幅保证稳定性。过流之外的停机原因需查看 `gimbal_protection_status.last_reason` 或故障快照，惯量变大并不能直接证明原来发生的是过流。

## 大惯量平台与双轴使能（2026-11-12）

USB `ENABLE=1` 现在同时开启 Yaw 和 Pitch，并以当前姿态建立保持目标；此前该命令强制关闭 Pitch，即使 `control_params.c` 默认使能也会被覆盖。仍可发 `PITCH=0` 显式切换到仅 Yaw，`PITCH=1` 重新开启 Pitch。STOP/ENABLE=0 仍会停机；下一次 ENABLE=1 恢复双轴。

电流规则保留当前放宽值：按现有 CAN 换算，连续超过 5.0 A 达 300 ms 才停机，启动宽限 200 ms，回到阈值以内清零，不再判定指令与反馈电流失配。关闭 Pitch 时，跳过它的 CAN 接收超时和过流判停并清零过流计数，避免未参与控制的电机拖停 Yaw；Yaw 关闭 LADRC 时仍有 PID 回退，因此仍保留其检查。Pitch 姿态仍用于 Yaw 的欧拉角速度换算，IMU 有效性及接近奇异姿态的限制仍保留。

当前双轴默认输出上限为 1.0（归一化满量程），原平台 LADRC 参数没有重新辨识。5 A 为软件反馈判停阈值，不是允许输出 5 A 的指令；GM6020 电流指令协议最大范围为 ±3 A，反馈比例仍需校准。大惯量平台的 b0、带宽和加速度需求需根据实测响应调整，不能仅凭软件构建判断误停消失。

若仍停机，先发送 USB `FAULT` 保存快照；reason=10 是连续过流，11 是当前参与控制轴的反馈超时，12 是 IMU 停更，6 是 Pitch 超过 ±80°。这些原因需分别定位。本次只编译及主机测试，不自动烧录。

## Pitch 两端行程采样

将遥控置于云台卸力档，退出自瞄和串口控制（USB 发 `STOP`），保持板子和电机反馈在线。校准不发电机运动指令；手动移动前托住俯仰机构，底盘保持水平，避免俯仰机构因重力落下。

1. USB 串口发送 `PCAL=RESET`，每条命令以换行结束。
2. 手动把 Pitch 移到下端，静止后发 `PCAL=LOW`；移到上端后发 `PCAL=HIGH`。回包同时给出 IMU 角和电机编码器角，单位是度。
3. 发 `PCAL=SHOW`。`measured_deg` 是按 IMU 角度从小到大排序的两端，`suggested_deg` 是两端各向内退 5° 后与现有 ±70° 软件范围的交集。

采样要求云台处于 RELAX、IMU 和 Pitch 反馈有效且姿态静止。结果仅在 RAM 保留，供确认方向与设置软限位；不自动改变限位，不写 Flash，不涉及 Yaw。代码没有独立的限位输入，因此不以电流或堵转作为自动寻边依据。

## 大惯量平台小角度起动

Yaw/Pitch LADRC 的默认到位容差均为 0.5°，保留 1.5 倍退出滞回和低角速度判定。低速进入到位状态后，角误差超过 0.75° 才退出。

小角度起动助力只在 LADRC 和该轴摩擦补偿开启时工作。误差超过死区退出门槛（且至少 0.08°）、不超过 2°，轴速低于 0.3°/s 并持续约 120 ms 后，才沿误差方向逐步增加助力。Yaw/Pitch 额外归一化输出分别限于 0.065/0.075；低速等待加助力总共最多 650 ms。轴速超过 0.8°/s、到位或开始反向刹车即撤掉助力。一个稳定目标只尝试一次，目标变化超过 0.1°或重新稳定后可再次触发。停止、关闭对应轴或 Pitch 向外限位会复位助力，原有电流保护与最终输出限幅仍生效。

可在调试器查看 `gimbal_yaw_breakaway` / `gimbal_pitch_breakaway` 的 `phase`、`output`。两轴的上限分别为 `gimbal_yaw_breakaway_max`、`gimbal_pitch_breakaway_max`，设为 0 可单独关闭助力；`YFF=0` / `PFF=0` 会同时关闭该轴原摩擦前馈与起动助力。

烧录后先用 `ENABLE=YAW`，在稳定姿态下分别测试 `YAWREL=1` 和 `YAWREL=-1`，观察是否起动、到位后是否振荡。Pitch 应先完成两端采样和方向检查，再在远离限位的位置启用，用同样的小步测试 `PITREL`。如果助力到顶仍不起动，不连续重复试探；先记录目标角、实际角、助力输出、反馈电流和 `FAULT`，区分静摩擦、负载与保护限制。软件测试验证控制输出和撤力逻辑，不代表实板最小可达角度。

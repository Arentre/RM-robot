# 两轴角度死区与串口范围

本次修改取消 Yaw 串口测试的步长、累计行程、角速度停机及额外 0.3 输出截断。Yaw 仍使用原 LADRC 参数和最短角度路径，控制器 `out_limit` 可通过 `YPARAM` 设置，最大为归一化 CAN 输出 1.0。非有限反馈、Pitch 姿态保护和 `STOP` 仍会停机。

Yaw/Pitch 均取消步长、相对起点行程和角速度停机限制。Pitch 保留绝对 IMU 姿态 ±70°：实际角度超过该范围会关闭两轴控制，`GET` 的 `stop=6`；目标超过该范围会返回 `err:命令名,pitch_limit`，不改写目标、不停机。在范围之外发送 `ENABLE=1` 同样会拒绝启用并记录 `stop=6`。限位停机和手动 `STOP` 均清除滤波尾巴及抖动输出。

Pitch 额外测试输出上限 0.1 已移除，Yaw/Pitch 由各自 LADRC 的 `out_limit` 控制（当前默认均为 0.3）。`YPARAM` / `PPARAM` 的输出上限参数均可设至 1.0；最终 CAN 输出仍限制在 ±1.0。非有限反馈停机（`stop=5`）和手动 `STOP`（`stop=1`）保留。旧停机码 2/3/4/7 保留编号供既有遥测脚本兼容，固件不再主动触发。

## 角度死区

Yaw 默认 0.2°，Pitch 默认 0.3°。只有目标误差进入死区且实测速度不超过 2°/s，LADRC 才进入静止状态：输出清零，重置 TD/ESO 残留，关闭该轴摩擦补偿，清除输出滤波尾巴。Yaw 的 dither 在死区中暂停。若将来启用并标定 Pitch 重力补偿，死区内仍保留该重力输出。

死区保持至误差超过入口的 1.5 倍，或速度超过 2°/s。角度参考不随反馈移动；超过边界立即恢复控制。允许死区内的稳态角度误差，不代表精度或快速响应已经经过实机验证。

```text
YDEAD=0.2
PDEAD=0.3
GET
```

单位为度，范围 0～3，0 关闭死区。`GET` 新增 `pit`、`pit_target`、`pitch_enable`，以及 `ydead=宽度,是否处于死区`、`pdead=宽度,是否处于死区`。原 `YPARAM` / `PPARAM` 的五参数顺序不变，修改它们不会覆盖死区宽度。设置只保存在 RAM 中。连续遥测保持原来的 41 通道。

## 发送方式

使用 ASCII 文本，每条追加 CRLF（`\r\n`），逐条发送并确认 `ack`。`%0.1f` 是脚本格式占位符，手动发送必须换成数字。

1. `ENABLE=1`：锁存当前姿态，先只启用 Yaw。
2. `PITCH=1`：启用 Pitch 并保持当前位置。
3. `PITREL=20.0`：从当前 IMU Pitch 向正方向移动 20°；观察运动后再发送下一条。
4. `STOP`：关闭两轴控制。

新增绝对命令 `PITABS=20.0`（也可 `PIT=20.0`），表示目标 IMU Pitch 为 +20°，不是编码器角度。Pitch 命令只受最终目标 ±70°限制，不再限制单次变化或相对起点行程。`YAWABS` / `YAWREL` 可跨越原有 ±35°测试范围，角度仍按一圈归一化；`YAWREL=360` 不代表执行一整圈。

烧录新固件后才会支持这些更改。主机行为测试直接编译 `User/component/ladrc.c` 与 `Utils/Tests/test_ladrc_deadband.c`，覆盖长时间小噪声不积累输出、死区滞回、高速穿越目标仍制动、±20°新目标立即退出死区及陀螺仪不可用时的速度反馈回退。
